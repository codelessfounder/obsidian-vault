Rules of operating the execute bucket:

1. "Execute" tasks should binary: You should be able to clearly note whether a task has been finished. 
2. No scope creep: Anything new should be added to the "Build" or "Explore" bucket
3. Auditing: Monthly. Tasks with no clear yield should be dropped or automated.

## Weekly Loop

| Area | Measurable Weekly Target | Metric / Verification | Weekly Review Question |
| :--- | :--- | :--- | :--- |
| **BJJ** | Attend 2–3 mat sessions | Session Count (`X/3`) | Did I get quality mat time and manage recovery? |
| **Gym** | Complete 3–4 strength sessions and log top sets/weight lifted | Session Count + Weight | Are lifts progressing without accumulating excess fatigue? |
| **Girlfriend** | 1 intentional, phone-free date night or quality block | Binary (`Done / Missed`) | Did we have focused, undistracted time together? |
| **Core Social & Family** | 1 check-in call or catch-up with family/close friends | Binary (`Done / Missed`) | Am I staying connected outside of work and obligations? |
| **Finances (Habits)** | 15-minute reconciliation (categorize spend, review cash buffer) | Binary (`Done / Missed`) | Did spending stay within my weekly subsistence cap? |
| **House (Deep Clean)** | 1 weekly reset block (laundry, fresh sheets, vacuum/bathroom) | Binary (`Done / Missed`) | Is my living environment friction-free for Monday? |
